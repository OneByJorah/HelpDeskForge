## What This Is

Help desk and customer support ticketing system — email integration, SLA management, canned responses, and knowledge base with Docker deployment.

## Quick Start

### npm

```bash
npm install helpdeskusto
```

### Docker

```bash
git clone https://github.com/OneByJorah/HelpDeskForge.git
cd HelpDeskForge
docker compose up -d
```

### From Source

```bash
git clone https://github.com/OneByJorah/HelpDeskForge.git
cd HelpDeskForge
npm install
npm run dev
```

## Features

- **Self-hosted** — run on your own hardware
- **Docker Compose** — full stack with one command
- **npm package** — install via npm
- **Dark theme** — operational UI

- **Ticketing system** — customer support ticket management
- **Email integration** — email-to-ticket conversion
- **SLA management** — response time tracking and escalation
- **Canned responses** — pre-written reply templates
- **Knowledge base** — self-service articles and FAQs
- **Docker Compose deployment** — full stack with one command
- **Dark theme** — support-operations aesthetic
